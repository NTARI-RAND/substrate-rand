# Tier 3: The Cloudy Platform

*The goal of Tier 3 is to implement the protocol and the JFA standard in the interface where prosumers offer and buy compute and storage.*

Cloudy is where members transact. It uses sohocloud-protocol for coordination and keeps its own member economy on top.
